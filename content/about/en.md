# Tech Echo Collective

**Tech Echo Collective** is a student-led, open collective for science, engineering, AI, games, and creative technology. It is deliberately lightweight: an umbrella for projects, technical notes, long-form discussion, and collaborative work.

> **Source scope:** the collective identity and philosophy on this page derive from the canonical organization README. Project classification, attribution, permissions, and current-work sections are maintained website policy linked to that identity.

## Domains

- **Science and mathematics** — physics, research maps, simulations, learning notes, and careful problem solving.
- **Engineering** — software, systems, tools, prototypes, and reproducible work.
- **AI and tools** — human-directed workflows, experiments, and critical technical discussion.
- **Games and interactive systems** — original games, mechanics, worldbuilding, and development logs.
- **Open source and documentation** — public repositories, transparent maintenance, and durable technical writing.
- **Community discussion** — one shared forum for proposals, questions, notes, and references.

## Philosophy

> Complex ideas should not disappear into silence. They should echo through projects, notes, systems, and games.

Tech Echo works in the space between theory and construction: from mathematics to mechanics, physics to simulation, AI to tools, games to systems, and ideas to working artifacts. We value clarity, technical depth, and concrete results over growth for its own sake.

## Project classification

### Tech Echo Project

A project initiated and stewarded by Tech Echo Collective. Its ownership and project leadership are stated explicitly; inclusion in the organization alone is not the definition.

### Member Project

An independently created and maintained project belonging to a Tech Echo member. Tech Echo may host, present, or support it without acquiring authorship, ownership, or management rights. **Physics Atlas is a Member Project created and maintained by Noah #001.**

### Collaboration

Work shared by multiple people or groups under an explicit project agreement. Attribution and authority follow that agreement, never an inferred hierarchy.

## Attribution and contributors

Ownership is shown first. Explicit featured roles such as creator or maintainer are shown separately from GitHub repository history. GitHub-linked contributor history comes from the Contributors API and is matched to Tech Echo members by stable numeric GitHub ID; a username change does not break the connection to a permanent member number. Anonymous commits are not included in that account-linked view.

Commit volume does not assign authority. Bots and incidental contributors are never promoted into featured roles automatically.

## Governance and permissions

Global community roles are **Founder, Administrator, Moderator, and Member**. They apply to the Tech Echo account and community surfaces.

Project roles apply only to the named project. Being a creator, maintainer, or contributor does not grant global administration, forum moderation, repository access, deployment access, or GitHub organization permissions. Tech Echo does not automate GitHub organization IAM from website attribution.

## One community

Tech Echo uses GitHub identity for accounts and assigns every member a permanent number. The community has one shared multilingual forum backed by GitHub Discussions. Categories organize topics; languages do not divide the community.

## Current work

- [Physics Atlas](https://atlas.techecho.org/) — an independently maintained member project mapping physics research ecosystems.
- [Cradles of Civilization](https://github.com/Tech-Echo-Collective/cradles-of-civilization) — an original text strategy game developed as a Tech Echo project.

The collective remains small, early, and experimental by design. The priority is to build real work, document it clearly, and open contribution paths responsibly.
